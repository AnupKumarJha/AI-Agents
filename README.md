# AI Agents

This repository explores the design and implementation of **Autonomous AI Agents**, including:
- Single LLM-powered agents
- Multi-agent collaboration frameworks
- Tool-using agents
- Real-world automation workflows

## 🧱 Architecture Concepts Covered
- Prompt-based agent reasoning
- Memory (short/long-term)
- Tool use (APIs, Search, Filesystem, Code Execution)
- Multi-Agent Planning + Critic Loops

## 🚀 Goal
Understand how to build agents that:
1. **Think** (reason step-by-step)
2. **Access Tools**
3. **Plan + Execute Tasks**
4. **Self-correct using feedback**

## 📦 Frameworks Included
- Autogen
- CrewAI
- LangChain
- Custom agent implementations (no-framework)
